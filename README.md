# AI 101

How AI really works, in 30-second stories. Read it at **https://amishah1998.github.io/ai101/**.

Chintu is a robot intern who read the entire internet. Across 11 short chapters, Chintu, Sharma ji (who trusts nothing without data) and Pinky (who trusts Chintu a little too much) show how large language models actually behave:

1. What is an LLM?
2. Prompting and context
3. What is LangChain for?
4. How does RAG work?
5. How do you test it?
6. How do tools work?
7. Agent or workflow?
8. When to use sub-agents?
9. Guardrails and humans
10. Memory, cost, MCP
11. Governance

Every card is one complete story, and every chapter can be read on its own. The Menu button searches every card, and Back returns you to where you were.

On a phone, open the link, tap Share, then Add to Home Screen to keep it like an app.

All people, companies, orders and numbers in the stories are made up, except where a source is linked. Written with AI assistance and checked by hand.
